## ⚡ Overview

**Classroom Feud** is an immersive, web-based quiz suite tailored specifically for ESL and English language teachers. Inspired by classic TV game shows, it allows instructors to transform vocabulary, grammar drills, and expression reviews into high-energy, team-based classroom competitions.

| Feature | Description |
| :--- | :--- |
| **🛠️ Interactive Constructor** | Build, arrange, and order your custom quiz rounds on the fly with precise score weightages. |
| **🤖 AI Prompt Integration** | Built-in ChatGPT prompt recipes for near-instant template injection and content creation. |
| **📊 Dual-Team Scoreboard** | Real-time score manipulation for competing student groups (Blue vs. Pink teams). |
| **📺 Screen Optimized** | High-contrast neon dark theme designed perfectly for classroom projectors and smartboards. |
