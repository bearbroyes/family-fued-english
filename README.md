# 🎮 Classroom Feud — English Teacher Game Show Suite

<p align="center">
  <strong>An interactive, web-based quiz game designed for English lessons and team competitions.</strong>
</p>

---

## ✨ Features

* **Custom Round Constructor:** Create and order your own quiz rounds with custom answers and weightages.
* **Fast Templates & AI Import:** Quick preset injection and ChatGPT prompt recipe integration for instant content generation.
* **Team Management:** Interactive scoreboard with customizable names (Blue and Pink teams) and simple points toggling.
* **Immersive Game Show UI:** Sleek, modern neon dark theme optimized for classroom screens and projectors.

## 🛠️ Tech Stack

* **Frontend:** Vite, TypeScript, HTML5, CSS3 / Tailwind
* **Deployment:** Hosted on GitHub Pages
